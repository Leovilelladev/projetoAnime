# Vinland Saga — Landing page

Landing page estática em HTML, CSS e JavaScript, criada para o exercício de publicação de uma página temática.

As imagens da pasta `assets/` são as referências visuais fornecidas para esta versão, combinando capa do anime, páginas do mangá e uma cena de Vinland.

## Rodar localmente

```bash
npm run dev
```

## Publicar na Vercel

Com a CLI da Vercel instalada e autenticada:

```bash
npx vercel --prod
```

O projeto não possui etapa de build: a Vercel serve o `index.html` diretamente.
